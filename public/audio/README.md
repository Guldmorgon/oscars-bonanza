# Musik (valfritt)

Lägg dina egna `.mp3`-filer i den här mappen (`public/audio/`). Saknas en fil spelas
ingen musik för det tillfället – appen fungerar helt utan musik.

Filnamn som appen letar efter:

| Fil               | Spelas                                                        |
| ----------------- | ------------------------------------------------------------- |
| `background.mp3`  | Loopar i bakgrunden under hela kvällen så det aldrig blir tyst |
| `final.mp3`       | Loopar under finalen                                           |
| `winner.mp3`      | Loopar på vinnarskärmen                                        |

Bakgrundsmusiken sänks automatiskt när en av de andra låtarna spelas, och höjs igen
efteråt. Musik kan slås av/på under **Inställningar**.

> Endast `.mp3` med rätt filnamn. Filerna laddas lokalt och kräver inget internet.
